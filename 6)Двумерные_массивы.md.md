## 1. Теоретическая шпаргалка: двумерные массивы в C#

Двумерный прямоугольный массив (`2D array`) — структура данных, представляющая собой таблицу фиксированного размера из строк и столбцов. Все строки имеют строго одинаковую длину.

### 1.1. Объявление и создание матрицы

```csharp
// 1. Создание пустой матрицы 3x4 (3 строки, 4 столбца), заполнена нулями
int[,] grid = new int;[3][4]

// 2. Инициализация значениями сразу при объявлении
int[,] map = {
    { 1, 2, 3 },
    { 4, 5, 6 },
    { 7, 8, 9 }
};

// 3. Обращение по индексам: [номер_строки, номер_столбца]
int val = map; // строка 0, столбец 2 -> значение 3[0][2]
map = 99;      // изменение центрального элемента[1]
```

### 1.2. Определение размеров через GetLength()

> **Важно:** свойство `map.Length` возвращает **общее** количество элементов во всей матрице (например, для 3x4 вернет 12). Для получения числа строк и столбцов используется метод `GetLength()`:

```csharp
int rows = map.GetLength(0); // измерение 0 -> количество СТРОК
int cols = map.GetLength(1); // измерение 1 -> количество СТОЛБЦОВ
```

### 1.3. Обход матрицы вложенными циклами

```csharp
// Внешний цикл отвечает за строки (i), внутренний — за столбцы (j)
for (int i = 0; i < map.GetLength(0); i++)
{
    for (int j = 0; j < map.GetLength(1); j++)
    {
        Console.Write($"{map[i, j],4} "); // форматированный вывод с отступом
    }
    Console.WriteLine(); // перевод строки после вывода каждого ряда
}
```

### 1.4. Типовые алгоритмы на квадратных матрицах (N x N)

```csharp
int[,] matrix = new int;[4]

// Главная диагональ: индексы строки и столбца равны (i == j)
for (int i = 0; i < matrix.GetLength(0); i++)
{
    matrix[i, i] = 1;
}

// Побочная диагональ: сумма индексов равна (N - 1) -> [i, N - 1 - i]
int n = matrix.GetLength(0);
for (int i = 0; i < n; i++)
{
    matrix[i, n - 1 - i] = 2;
}

// Поиск глобального максимума в матрице
int maxVal = matrix;[0]
int maxRow = 0, maxCol = 0;

for (int i = 0; i < matrix.GetLength(0); i++)
{
    for (int j = 0; j < matrix.GetLength(1); j++)
    {
        if (matrix[i, j] > maxVal)
        {
            maxVal = matrix[i, j];
            maxRow = i;
            maxCol = j;
        }
    }
}
```

## 3. Разбор типовых примеров

### Пример 1. Отрисовка символьной карты с рамкой

```csharp
using System;

class Program
{
    static void Main()
    {
        const int rows = 5;
        const int cols = 8;
        char[,] dungeon = new char[rows, cols];

        // Заполнение карты: границы — решетки, центр — точки
        for (int i = 0; i < rows; i++)
        {
            for (int j = 0; j < cols; j++)
            {
                if (i == 0 || i == rows - 1 || j == 0 || j == cols - 1)
                    dungeon[i, j] = '#'; // стена
                else
                    dungeon[i, j] = '.'; // свободный проход
            }
        }

        // Размещение героя
        dungeon = '@';[2][3]

        // Вывод карты в консоль
        for (int i = 0; i < dungeon.GetLength(0); i++)
        {
            for (int j = 0; j < dungeon.GetLength(1); j++)
            {
                if (dungeon[i, j] == '@')
                {
                    Console.ForegroundColor = ConsoleColor.Green;
                    Console.Write(dungeon[i, j] + " ");
                    Console.ResetColor();
                }
                else
                {
                    Console.Write(dungeon[i, j] + " ");
                }
            }
            Console.WriteLine();
        }
    }
}
```

### Пример 2. Подсчет суммы элементов по строкам

```csharp
using System;

class Program
{
    static void Main()
    {
        int[,] sectorThreats = {
            { 10, 20, 15 },
            { 5,  40, 25 },
            { 30, 10, 50 }
        };

        for (int i = 0; i < sectorThreats.GetLength(0); i++)
        {
            int rowSum = 0;
            for (int j = 0; j < sectorThreats.GetLength(1); j++)
            {
                rowSum += sectorThreats[i, j];
            }
            Console.WriteLine($"Сектор {i + 1}: суммарный уровень угрозы = {rowSum}");
        }
    }
}
```

## 4. Обязательные технические требования

1. **Размерность матрицы:** размер игрового поля составляет не менее 5x5 клеток. Размеры считываются динамически через `.GetLength(0)` и `.GetLength(1)`, а не "зашиваются" жесткими константами во вложенных циклах.
2. **Форматированный вывод:** отрисовка сетки реализуется вложенными циклами с ровными отступами между столбцами и переводом строки после каждого ряда.
3. **Безопасность индексов:** любые действия пользователя по выбору координат `[x, y]` сопровождаются проверкой условия: `x >= 0 && x < rows && y >= 0 && y < cols`.
4. **Аналитический блок:** наличие алгоритмов вычисления сумм по строкам/столбцам, поиска глобального экстремума и сканирования диагоналей.
