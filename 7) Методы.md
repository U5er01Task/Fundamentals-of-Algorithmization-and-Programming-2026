## 1. Теоретическая шпаргалка: методы в C#

Метод — именованный блок кода, решающий обособленную подзадачу и способный принимать входные аргументы и возвращать результат.

### 1.1. Анатомия метода и передача по значению

По умолчанию базовые типы передаются по значению: метод получает копию данных.

```csharp
// Модификаторы + тип возвращаемого значения + ИмяМетода(Параметры)
static double CalculateCriticalDamage(int baseDamage, double multiplier)
{
    if (baseDamage <= 0 || multiplier < 1.0) return 0;
    return baseDamage * multiplier;
}
```

### 1.2. Модификаторы параметров: ref, out, params

- `ref` — передача аргумента по ссылке. Переменная **обязана** быть инициализирована до вызова; метод может как читать, так и изменять её значение.
- `out` — выходной параметр. Метод **обязан** присвоить переменной значение до завершения работы. Удобен для возврата нескольких значений.
- `params` — позволяет передавать произвольное количество аргументов одного типа через запятую или в виде массива.

```csharp
// 1. Использование ref (модификация исходного ресурса)
static void ConsumeStamina(ref int currentStamina, int cost)
{
    currentStamina = Math.Max(0, currentStamina - cost);
}

// 2. Использование out (возврат нескольких метрик)
static bool TryAnalyzeCombatLog(int[] logs, out int maxHit, out double avgHit)
{
    if (logs == null || logs.Length == 0)
    {
        maxHit = 0;
        avgHit = 0.0;
        return false;
    }

    int sum = 0;
    maxHit = logs;
    for (int i = 0; i < logs.Length; i++)
    {
        if (logs[i] > maxHit) maxHit = logs[i];
        sum += logs[i];
    }
    avgHit = (double)sum / logs.Length;
    return true;
}

// 3. Использование params (гибкий расчет)
static int AggregateThreat(params int[] threatLevels)
{
    int total = 0;
    foreach (int t in threatLevels) total += t;
    return total;
}
```

### 1.3. Перегрузка методов (Method Overloading)

Методы в одном классе могут иметь одинаковое имя, если их сигнатуры отличаются количеством или типами входных параметров:

```csharp
static void CastSpell(string spellName)
{
    Console.WriteLine($"Заклинание: {spellName}");
}

static void CastSpell(string spellName, int powerTier, bool isEmpowered)
{
    int finalPower = isEmpowered ? powerTier * 2 : powerTier;
    Console.WriteLine($"Заклинание: {spellName} | Мощность: {finalPower}");
}
```

### 1.4. Рекурсивные методы

Метод, вызывающий сам себя для решения подзадачи меньшей размерности. Обязан содержать базовый случай (условие выхода):

```csharp
// Расчет сложного коэффициента сопротивления брони
static int CalculateArmorDegradation(int armorValue, int roundsRemaining)
{
    if (roundsRemaining <= 0) return armorValue; // Базовый случай
    return CalculateArmorDegradation((int)(armorValue * 0.85), roundsRemaining - 1);
}
```

## 3. Критерии сложности задач

Каждое из 5 заданий варианта обязано удовлетворять требованиям:

1. **Никаких глобальных переменных:** обмен данными между `Main` и методами происходит строго через параметры и `return`.
2. **Возврат составных состояний (`out` / `bool`):** методы анализа обязаны валидировать входные данные, возвращать статус успеха (`bool`) и выносить метрики в выходные параметры `out`.
3. **Модификация структур на месте (`ref`):** изменения ресурсов и матриц должны производиться без создания мусорных дубликатов.
4. **Перегрузка сигнатур:** минимум 1 блок задач требует реализации двух или трех перегрузок одного метода для разных контекстов вызова.
5. **Вариативные аргументы (`params`):** минимум 1 метод агрегирует цепочки параметров переменной длины.
6. **Рекурсивный алгоритм:** наличие рекурсивного расчета (цепочки деградации, расчет глубины затухания, расчет сопротивления).
7. **Матричные алгоритмы:** методы обработки двумерных структур с динамическим определением границ через `GetLength(0)` и `GetLength(1)`.

5. **`ProcessCloudDensityGrid` (матрица):** Метод анализа фронтальной плотности облаков `int[,] cloudGrid`. Сканирует плотность тумана по строкам, строит безопасный оптический коридор для работы лазерного высотомера и выводит карту в консоль.

5. **`AnalyzeSeismicArrayMatrix` (матрица):** Метод анализа двумерной сетки сейсмодатчиков лунной базы `double[,] sensorGrid`. Вычисляет эпицентр подземного толчка (ячейка с максимальной амплитудой), проверяет целостность диагональных линий датчиков и выводит карту поля вибраций.
