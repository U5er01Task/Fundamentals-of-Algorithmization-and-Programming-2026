## 1. Теоретическая шпаргалка: статические и вложенные типы

### 1.1. Статические элементы обычного класса

Модификатор `static` привязывает поле, свойство или метод не к конкретному объекту в управляемой куче (`heap`), а к **самому типу данных** (метаданным класса).

- Статическое поле существует в памяти в **единственном экземпляре** для всего приложения, независимо от того, сколько объектов класса было создано (или не создано вовсе).
- Обращение к статическим элементам выполняется строго через имя класса: `ClassName.StaticElement`, а не через ссылку на экземпляр.
- Статический метод **не имеет доступа** к ключевому слову `this` и не может напрямую обращаться к нестатическим полям и методам своего класса, пока явно не создаст экземпляр или не получит его через параметр.

```csharp
public class User
{
    // Общий счетчик для всех пользователей
    public static int TotalUsersCount { get; private set; }

    public string Name { get; }

    public User(string name)
    {
        Name = name;
        TotalUsersCount++; // инкремент при создании каждого нового объекта
    }
}
```

### 1.2. Статический конструктор

Специальный конструктор, предназначенный для однократной инициализации статических полей или выполнения действий перед первым обращением к классу.

- **Не имеет модификаторов доступа** (нельзя объявить `public` или `private`).
- **Не принимает параметров** (перегрузка статического конструктора невозможна).
- Вызывается исполняющей средой CLR автоматически ровно один раз: в момент создания первого экземпляра класса или при первом обращении к любому статическому элементу.

```csharp
public class ConfigManager
{
    public static string SystemVersion { get; }

    static ConfigManager()
    {
        SystemVersion = "v2.5.1-Release";
        Console.WriteLine("[System]: Статический конструктор ConfigManager инициализирован.");
    }
}
```

### 1.3. Статический класс (static class)

Класс, помеченный модификатором `static`, выступает исключительно контейнером для служебных методов и статических констант (например, `Math` или `Console`).

- От статического класса **нельзя наследоваться** (он неявно `sealed` и `abstract`).
- Экземпляр статического класса **нельзя создать** через оператор `new`.
- Все элементы внутри статического класса **обязаны быть статическими**.
- Внутри статического класса нельзя объявлять нестатические конструкторы.

```csharp
public static class MathValidator
{
    public static bool IsInRange(int value, int min, int max)
    {
        return value >= min && value <= max;
    }
}
```

### 1.4. Вложенные классы (Nested Classes)

Класс, объявленный внутри тела другого класса (внешнего контейнера).

- Вложенный класс логически группирует вспомогательные сущности, нужные только основному классу.
- Вложенный класс может иметь **любой модификатор доступа**: `public`, `internal`, `protected`, а также `private`. Закрытый (`private`) вложенный класс невидим снаружи и доступен только коду внешнего класса.
- Вложенный класс имеет доступ ко всем элементам внешнего класса (включая закрытые `private` и статические поля). Но для доступа к нестатическим полям внешнего класса он должен хранить ссылку на его экземпляр.

```csharp
public class Order
{
    private decimal _totalAmount;

    // Публичный вложенный класс: снаружи доступен как Order.Receipt
    public class Receipt
    {
        public void Print(Order order)
        {
            // Прямой доступ к закрытому полю _totalAmount родительского класса
            Console.WriteLine($"Чек на сумму: {order._totalAmount} руб.");
        }
    }
}
```

## 2. Архитектура практического задания

Разрабатывается подсистема процессинга транзакций **«Электронный расчетный центр» (`BankingHub`)**.

### Состав проекта:

1. **`CurrencyConverter` (Статический класс):** статические курсы валют, статический конструктор, статические расчетные методы.
2. **`BankAccount` (Обычный класс со статическими элементами):**
   - Статическое поле/свойство общего пула транзакций;
   - Внутреннее состояние конкретного счета (номер, баланс);
   - Фабричный статический метод создания счетов.
3. **`BankAccount.StatementRecord` (Вложенный закрытый класс):** строка выписки операций по счету, доступная для управления только самому банку.
4. **`BankAccount.SecurityAudit` (Вложенный публичный класс):** модуль аудита, имеющий доступ к внутренней истории счета для выявления подозрительных операций.
5. **`Program.cs`:** точка входа, демонстрирующая жизненный цикл статических конструкторов и логику работы вложенных классов.

## 3. Технические требования к реализации

### Шаг 1. Статический класс `CurrencyConverter`

1. Объявить `public static class CurrencyConverter`.
2. Статические свойства:
   - `public static double UsdRate { get; private set; }`
   - `public static double EurRate { get; private set; }`
3. Статический конструктор:
   - Выводит сообщение в консоль: `"[CurrencyConverter]: Загрузка курсов валют..."`;
   - Устанавливает базовые значения: `UsdRate = 92.5;`, `EurRate = 100.2;`.
4. Статические методы:
   - `public static void UpdateRates(double newUsd, double newEur)` — обновляет курсы с проверкой (курсы должны быть строго `> 0`);
   - `public static decimal ConvertToRub(decimal foreignAmount, string currencyCode)` — переводит сумму в рубли в зависимости от валюты (`"USD"` или `"EUR"`). При некорректном коде возвращает исходную сумму.

### Шаг 2. Класс `BankAccount` со статическими элементами

1. Статические элементы класса:
   - `private static int _nextAccountNumber;` — глобальный автоинкремент для генерации уникальных номеров счетов;
   - `public static int TotalAccountsCreated { get; private set; }` — счетчик созданных счетов;
   - `public static decimal GlobalBankReserves { get; private set; }` — совокупный баланс всех счетов банка;
   - Статический конструктор: инициализирует `_nextAccountNumber = 10001;`, выводит сервисное сообщение о старте ядра банка.
2. Экземплярные элементы класса:
   - Свойства: `public int AccountNumber { get; }`, `public string OwnerName { get; }`, `public decimal Balance { get; private set; }`;
   - Поле истории: массив объектов закрытого вложенного типа `StatementRecord[] _records;` на 10 элементов;
   - Поле-счетчик: `private int _recordCount = 0;`.
3. Конструктор экземпляра:
   - `private BankAccount(string owner, decimal initialBalance)` — закрытый конструктор! Номер счета назначается автоматически из `_nextAccountNumber++`.
4. Статический фабричный метод:
   - `public static BankAccount OpenAccount(string owner, decimal initialDeposit)` — проверяет депозит (не менее 1000 рублей). При успехе вызывает закрытый конструктор, инкрементирует `TotalAccountsCreated`, увеличивает `GlobalBankReserves` и возвращает готовый объект.

### Шаг 3. Вложенные классы внутри `BankAccount`

1. **Закрытый вложенный класс `StatementRecord` (`private class`):**
   - Служит для хранения единичной транзакции.
   - Свойства: `public DateTime Timestamp { get; }`, `public string OperationType { get; }`, `public decimal Amount { get; }`.
   - Конструктор: инициализирует текущее системное время (`DateTime.Now`), тип операции и сумму.
   - Закрытый метод в `BankAccount`: `private void AddRecord(string op, decimal amount)` — добавляет новую запись в массив `_records`, сдвигая счетчик `_recordCount`.
2. **Публичный вложенный класс `SecurityAudit` (`public class`):**
   - Служит для проведения внешней ревизии конкретного счета.
   - Метод `public static void Inspect(BankAccount account)`:
     - Получает прямой доступ к закрытому массиву `account._records` и закрытому полю `account._recordCount`;
     - Выводит полный протокол операций клиента;
     - Если какая-либо транзакция превышает 50 000 руб., выводит предупреждение о финансовом мониторинге.

### Шаг 4. Бизнес-методы `BankAccount`

- `public void Deposit(decimal amount)` — пополняет баланс, обновляет `GlobalBankReserves` и вызывает `AddRecord("Пополнение", amount)`.
- `public bool Withdraw(decimal amount)` — списывает средства при их достаточности, корректирует резервы банка и фиксирует `AddRecord("Снятие", amount)`.

### Шаг 5. Моделирование в `Program.cs`

В методе `Main`:

1. Вызвать метод конвертера валют `CurrencyConverter.ConvertToRub(100, "USD")` **до** создания банковских счетов, зафиксировав в консоли момент вызова статического конструктора конвертера.
2. Попытаться открыть счет с депозитом 500 рублей через фабричный метод, обработать отказ.
3. Открыть два счета через `BankAccount.OpenAccount`: для `"Иван Иванов"` (50 000 руб.) и `"Анна Смирнова"` (20 000 руб.).
4. Выполнить несколько транзакций (пополнение, снятие, конвертация валюты).
5. Обратиться к статическим свойствам `BankAccount.TotalAccountsCreated` и `BankAccount.GlobalBankReserves`, выведя сводку по банку.
6. Запустить аудит счета через публичный вложенный класс: `BankAccount.SecurityAudit.Inspect(account1)`.
7. Показать в комментариях ошибку компиляции при попытке создать объект закрытого вложенного класса снаружи (`new BankAccount.StatementRecord()`).
