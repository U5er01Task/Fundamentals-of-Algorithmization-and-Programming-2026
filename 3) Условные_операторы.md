## 2. Разбор типовых примеров

### Пример 1. Одиночное и парное условие (`if-else`)

**Условие:** Программа считывает с клавиатуры целое число — скорость движения автомобиля в км/ч. Если скорость превышает 60 км/ч, вывести величину штрафа (500 руб.) и предупреждение. Иначе вывести сообщение о том, что скорость допустима.

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите скорость движения (км/ч): ");
        if (!int.TryParse(Console.ReadLine(), out int speed))
        {
            Console.WriteLine("Ошибка: некорректный ввод числа.");
            return;
        }

        const int maxAllowedSpeed = 60;

        if (speed > maxAllowedSpeed)
        {
            int overspeed = speed - maxAllowedSpeed;
            Console.WriteLine($"Нарушение! Превышение на {overspeed} км/ч.");
            Console.WriteLine("Штраф: 500 рублей.");
        }
        else
        {
            Console.WriteLine("Скорость в пределах нормы. Нарушений нет.");
        }
    }
}
```

**Разбор логики:**

1. Метод `int.TryParse` предотвращает аварийное завершение программы при вводе букв или символов.
2. Константа `maxAllowedSpeed` вынесена отдельно для избежания «магических чисел».
3. Проверяется предикат `speed > maxAllowedSpeed`. Если он возвращает `true`, управление передается первому блоку; если `false` — блоку `else`.

### Пример 2. Каскадное ветвление (`else if`) по числовым диапазонам

**Условие:** Пользователь вводит температуру охлаждающей жидкости двигателя (°C). Определить и вывести состояние системы:

- Менее 40: «Холодный двигатель (прогрев)»;
- От 40 до 84 включительно: «Рабочий режим до рабочей температуры»;
- От 85 до 105 включительно: «Оптимальная рабочая температура»;
- Выше 105: «Критический перегрев! Заглушите мотор».

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите температуру ОЖ (°C): ");
        if (!double.TryParse(Console.ReadLine(), out double temp))
        {
            Console.WriteLine("Некорректный ввод.");
            return;
        }

        if (temp < 40)
        {
            Console.WriteLine("Холодный двигатель (прогрев).");
        }
        else if (temp <= 84)
        {
            Console.WriteLine("Рабочий режим до рабочей температуры.");
        }
        else if (temp <= 105)
        {
            Console.WriteLine("Оптимальная рабочая температура.");
        }
        else
        {
            Console.WriteLine("Критический перегрев! Заглушите мотор!");
        }
    }
}
```

**Разбор логики:**

- Каскад проверяется сверху вниз. Если `temp = 75`, первая ветка (`< 40`) вернет `false`. Вторая ветка (`<= 84`) вернет `true`. Программа выведет сообщение и проигнорирует все последующие ветки.

### Пример 3. Сложные логические условия (`&&`, `||`, `!`)

**Условие:** Проверить, может ли существовать треугольник с заданными длинами сторон $a$, $b$, $c$, и определить, является ли он равносторонним.

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите сторону a: ");
        double a = double.Parse(Console.ReadLine());
        Console.Write("Введите сторону b: ");
        double b = double.Parse(Console.ReadLine());
        Console.Write("Введите сторону c: ");
        double c = double.Parse(Console.ReadLine());

        // Теорема о неравенстве треугольника
        bool isValidTriangle = (a + b > c) && (a + c > b) && (b + c > a);

        if (!isValidTriangle)
        {
            Console.WriteLine("Треугольник с такими сторонами существовать не может.");
        }
        else
        {
            Console.WriteLine("Треугольник существует.");
            if (a == b && b == c)
            {
                Console.WriteLine("Этот треугольник — равносторонний.");
            }
        }
    }
}
```

**Разбор логики:**

- Оператор `&&` (И) требует одновременного выполнения всех трех условий неравенства.
- Инверсия `!` проверяет ложность флага `isValidTriangle`.

### Пример 4. Оператор выбора `switch`

**Условие:** Реализовать простое консольное меню выбора протокола диагностики автомобиля: 1 — Двигатель, 2 — Трансмиссия, 3 — Тормозная система (ABS), 4 — Подушки безопасности (SRS).

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("=== МЕНЮ ДИАГНОСТИКИ ===");
        Console.WriteLine("1. Блок управления двигателем (ECU)");
        Console.WriteLine("2. Автоматическая трансмиссия (TCU)");
        Console.WriteLine("3. Антиблокировочная система (ABS)");
        Console.WriteLine("4. Система подушек безопасности (SRS)");
        Console.Write("Выберите пункт (1-4): ");

        int choice = int.Parse(Console.ReadLine());

        switch (choice)
        {
            case 1:
                Console.WriteLine("Запрос кодов ошибок ECU... Ошибок нет.");
                break;
            case 2:
                Console.WriteLine("Чтение параметров давления масла в TCU...");
                break;
            case 3:
                Console.WriteLine("Опрос датчиков скорости вращения колес...");
                break;
            case 4:
                Console.WriteLine("Проверка сопротивления пиропатронов SRS...");
                break;
            default:
                Console.WriteLine("Ошибка: выбран несуществующий раздел меню.");
                break;
        }
    }
}
```
