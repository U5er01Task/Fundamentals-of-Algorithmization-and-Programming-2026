## 1. Теоретическая шпаргалка: наследование и приведение типов

Наследование — фундаментальный принцип ООП, позволяющий создать новый дочерний (производный) класс на основе существующего родительского (базового) класса, повторно используя его состояние и поведение.

### 1.1. Базовый синтаксис и вызов конструктора родителя

В C# поддерживается только **одиночное наследование** классов (класс может иметь только одного прямого предка). Для передачи параметров в конструктор базового класса используется ключевое слово `base`:

```csharp
public class Vehicle
{
    public string Model { get; }
    protected int Speed; // доступно в текущем и дочерних классах

    public Vehicle(string model, int speed)
    {
        Model = model;
        Speed = speed;
    }
}

public class Car : Vehicle
{
    public int FuelLevel { get; set; }

    // Конструктор потомка делегирует инициализацию родителю через : base(...)
    public Car(string model, int speed, int fuel) : base(model, speed)
    {
        FuelLevel = fuel;
    }
}
```

### 1.2. Модификаторы доступа в контексте наследования

- `public` — доступен везде.
- `private` — доступен только внутри объявившего класса (потомки его наследуют, но прямого доступа не имеют).
- `protected` — доступен внутри объявившего класса и во **всех производных классах** (снаружи закрыт).
- `internal` — доступен только внутри текущей сборки (проекта).
- `protected internal` — доступен в текущей сборке либо в наследниках из других сборок.
- `private protected` — доступен только в наследниках, находящихся в этой же сборке.

### 1.3. Модификатор sealed (запечатывание)

Ключевое слово `sealed` запрещает дальнейшее развитие иерархии:

1. **Запечатанный класс:** от него нельзя наследоваться. Компилятор выдаст ошибку при попытке указать его в качестве базового:
   ```csharp
   public sealed class FinalSecurityModule { } // Наследование запрещено
   ```
2. **Запечатанный метод:** запрещает дальнейшее переопределение виртуального метода в цепочке потомков:
   ```csharp
   public sealed override void Initialize() { } // Переопределить ниже нельзя
   ```

### 1.4. Проверка и приведение типов: операторы is и as

Базовый класс может выступать ссылочным типом для хранения любого своего потомка (полиморфизм ссылок): `Vehicle v = new Car("Lada", 120, 40);`. Для работы со специфичными членами потомка требуется приведение типа.

#### Оператор is

Проверяет, совместим ли объект с указанным типом. Поддерживает сопоставление с шаблоном (pattern matching):

```csharp
if (vehicle is Car car) // Проверяет тип и сразу объявляет типизированную переменную
{
    Console.WriteLine($"Топливо автомобиля: {car.FuelLevel}");
}
```

#### Оператор as

Выполняет мягкое ссылочное приведение типов. Если объект несовместим, операция **не выбрасывает исключение**, а возвращает `null`:

```csharp
Car car = vehicle as Car;
if (car != null)
{
    car.FuelLevel += 10;
}
```

### 1.5. Виртуальные члены: virtual, override и base

Чтобы переопределить логику родительского метода, в базовом классе метод помечают как `virtual`, а в производном — `override`. Внутри переопределенного метода можно вызвать исходный алгоритм через `base.MethodName()`:

```csharp
public class Vehicle
{
    public virtual void Start() => Console.WriteLine("Двигатель запущен.");
}

public class Truck : Vehicle
{
    public override void Start()
    {
        base.Start(); // Вызов базовой логики
        Console.WriteLine("Прокачка пневмосистемы завершена.");
    }
}
```

Разрабатывается иерархия классов для автоматизированной системы диспетчеризации **«Транспортный хаб мегаполиса»**.

### Схема наследования:

- **`Transport` (Базовый класс):** общие характеристики, защищенные поля, виртуальные методы.

## 3. Технические требования к реализации

### Шаг 1. Проектирование базового класса `Transport`

1. Поля:
   - `protected string TransportId` — уникальный инвентарный номер;
   - `protected int CurrentSpeed` — текущая скорость движения (км/ч);
   - `private double _mileageKm` — общий пробег (инкапсулирован полностью).
2. Свойства:
   - `public string Id => TransportId;` (только для чтения);
   - `public double Mileage => _mileageKm;` (только для чтения);
   - `public int Speed { get => CurrentSpeed; protected set => CurrentSpeed = Math.Max(0, value); }`
3. Конструктор:
   - `public Transport(string id, double mileage)` — инициализирует идентификатор и базовый пробег.
4. Методы:
   - `public virtual void Move(double distanceKm)` — увеличивает общий пробег `_mileageKm += distanceKm` и выводит базовый отчет о перемещении;
   - `public virtual void DisplayInfo()` — выводит в консоль сводку по Id, скорости и пробегу.

### Шаг 2. Реализация класса `PublicBus`

1. Наследуется от `Transport`.
2. Дополнительные члены:
   - `public int PassengerCapacity { get; }` — максимальная вместимость;
   - `public int CurrentPassengers { get; private set; }` — текущее количество людей в салоне.
3. Конструктор:
   - Принимает `id`, `mileage`, `passengerCapacity` и передает первые два параметра в `base(id, mileage)`.
4. Методы:
   - `public void BoardPassengers(int count)` — производит посадку с контролем лимита вместимости;
   - `public override void Move(double distanceKm)` — переопределяет базовое движение: вызывает `base.Move(distanceKm)` и выводит сообщение: `"Автобус следует по городскому маршруту с остановками"`.

### Шаг 3. Реализация запечатанного класса `ElectricScooter` (sealed)

1. Объявлен с ключевым словом `sealed`: наследование от этого класса запрещено.
2. Дополнительные члены:
   - `private int _batteryPercent` — заряд аккумулятора (0–100%).
3. Конструктор:
   - Принимает `id`, `mileage`, `batteryPercent` с вызовом `base(id, mileage)`.
4. Методы:
   - `public void Recharge()` — восстанавливает заряд батареи до 100%;
   - `public override void Move(double distanceKm)` — переопределяет метод: проверяет заряд (расход 2% на 1 км). Если заряда недостаточно, движение блокируется; при успехе расходует заряд и вызывает `base.Move(distanceKm)`.

### Шаг 4. Реализация класса `CargoTruck`

1. Наследуется от `Transport`.
2. Дополнительные члены:
   - `public double MaxCargoTons { get; }`
   - `public bool HasTrailer { get; set; }`
3. Конструктор:
   - Принимает `id`, `mileage`, `maxCargoTons`, `hasTrailer` с вызовом `base(id, mileage)`.
4. Методы:
   - `public override void DisplayInfo()` — вызывает `base.DisplayInfo()` и дописывает статус прицепа и грузоподъемность;
   - `public void UnloadCargo()` — специфичный метод выгрузки кузова.

### Шаг 5. Полиморфная обработка в `Program.cs` (is и as)

В методе `Main`:

1. Создать единый полиморфный массив базового типа `Transport[] fleet = new Transport[4];`, содержащий:
   - 1 городской автобус (`PublicBus`);
   - 2 электросамоката (`ElectricScooter`) с разным уровнем заряда;
   - 1 грузовой тягач (`CargoTruck`).
2. В цикле `foreach` обойти весь автопарк и вызвать общий метод `Move(10.0)` для дистанции в 10 км.
3. Продемонстрировать **оператор is**:
   - Найти в массиве самокаты через `item is ElectricScooter scooter`, проверить остаток заряда и, если он ниже 20%, вызвать `scooter.Recharge()`.
4. Продемонстрировать **оператор as**:
   - Попытаться привести каждый элемент массива к `CargoTruck truck = item as CargoTruck;`.
   - Если результат не равен `null`, вызвать специальный метод `truck.UnloadCargo()`.
5. Показать попытку наследования от `ElectricScooter` в комментариях к коду, зафиксировав сообщение компилятора о невозможности наследования от `sealed`-типа.
