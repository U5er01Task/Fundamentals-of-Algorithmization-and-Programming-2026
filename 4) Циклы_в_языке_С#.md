## 1. Цель и задачи работы

### Цель работы

Закрепить практические навыки применения циклических конструкций (`while`, `do-while`, `for`) во взаимосвязи с базовыми типами данных, условными операторами (`if-else`) и оператором выбора (`switch`) на примере создания консольной пошаговой игры.

### Задачи

1. Реализовать цикл с постусловием `do-while` для валидации пользовательского ввода.
2. Применить цикл с предусловием `while` для организации пошагового игрового цикла.
3. Использовать цикл со счетчиком `for` для последовательной смены волн противников и визуализации шкал.
4. Научиться управлять логикой итераций с помощью операторов `break` и `continue`.
5. Освоить командную разработку, декомпозицию задач и код-ревью в парах.

## 3. Разбор типовых примеров

### Пример 1. Меню действий и валидация через do-while

Цикл гарантирует хотя бы один опрос игрока и предотвращает падение программы при некорректном вводе.

```csharp
using System;

class Program
{
    static void Main()
    {
        int action;
        bool isValid;

        do
        {
            Console.WriteLine("Выберите действие:");
            Console.WriteLine("1 — Обычная атака\n2 — Специальный прием\n3 — Защитная стойка\n4 — Использовать расходник");
            Console.Write("Ваш выбор: ");

            isValid = int.TryParse(Console.ReadLine(), out action) && action >= 1 && action <= 4;

            if (!isValid)
            {
                Console.ForegroundColor = ConsoleColor.Red;
                Console.WriteLine("Ошибка: введите цифру от 1 до 4!\n");
                Console.ResetColor();
            }
        } while (!isValid);

        Console.WriteLine($"Принято действие: {action}");
    }
}
```

### Пример 2. Пошаговая битва через while

Сражение продолжается до момента, пока здоровье одного из участников не опустится до нуля или ниже.

```csharp
using System;

class Program
{
    static void Main()
    {
        int playerHp = 100;
        int enemyHp = 70;
        Random rnd = new Random();

        Console.WriteLine("=== БОЙ НАЧАЛСЯ ===");

        while (playerHp > 0 && enemyHp > 0)
        {
            int playerDamage = rnd.Next(12, 22);
            enemyHp -= playerDamage;
            Console.WriteLine($"Игрок нанес {playerDamage} урона. У противника: {Math.Max(0, enemyHp)} HP");

            if (enemyHp <= 0)
            {
                Console.WriteLine("Противник повержен!");
                break;
            }

            int enemyDamage = rnd.Next(8, 16);
            playerHp -= enemyDamage;
            Console.WriteLine($"Противник нанес {enemyDamage} урона. У игрока: {Math.Max(0, playerHp)} HP\n");
        }

        if (playerHp <= 0)
        {
            Console.WriteLine("Поражение! Игра окончена.");
        }
    }
}
```

### Пример 3. Индикаторы состояния и смена этапов через for

Цикл со счетчиком применяется для повторения одинаковых символов шкалы здоровья и фиксации номеров этапов.

```csharp
using System;

class Program
{
    static void Main()
    {
        int currentHp = 6; // из 10
        int maxHp = 10;

        Console.Write("Здоровье: [");
        for (int i = 0; i < currentHp; i++)
        {
            Console.Write("#");
        }
        for (int i = 0; i < (maxHp - currentHp); i++)
        {
            Console.Write("-");
        }
        Console.WriteLine($"] ({currentHp}/{maxHp})");
    }
}
```

## 4. Технические требования к проекту

Программа пишется строго в процедурном стиле внутри метода `Main`.

1. **Главный цикл игры (`while`):** сессия длится до победы над всеми противниками или гибели героя.
2. **Волны противников (`for`):** минимум 3 последовательных соперника (каждый следующий обладает увеличенным запасом очков и силы).
3. **Меню выбора (`do-while` + `switch`):**
   - 1: Базовая атака (стабильный урон).
   - 2: Специальная способность (повышенный урон, расходует вторичный ресурс).
   - 3: Оборона (уменьшает получаемый в ход противника урон вдвое).
   - 4: Восстановление ресурса (ограниченный запас использований на всю игру).
4. **Визуализация (`for`):** перед каждым ходом в консоль выводятся текстовые полосы состояния ключевых параметров персонажей.
