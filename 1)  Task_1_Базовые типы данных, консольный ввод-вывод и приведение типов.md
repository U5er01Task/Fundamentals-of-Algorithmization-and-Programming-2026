# Практическая работа: Базовые типы данных, консольный ввод-вывод и приведение типов в C#

## 1. Консольный ввод и вывод данных

В платформе .NET для взаимодействия с консолью используется статический класс `System.Console`.

### Основные методы вывода

- `Console.Write(value)` — выводит переданное значение на экран без перевода курсора на следующую строку.
- `Console.WriteLine(value)` — выводит переданное значение и автоматически осуществляет переход на новую строку.

```csharp
Console.Write("Введите ваше имя: ");
Console.WriteLine("Привет, студент!");
```

### Основные методы ввода

- `Console.ReadLine()` — считывает поток символов до нажатия клавиши Enter и возвращает результат в виде строки (`string`). Если ввод пуст, возвращает пустую строку или `null`.
- `Console.Read()` — считывает следующий отдельный символ из входного потока и возвращает его целочисленный код ASCII/Unicode (`int`).
- `Console.ReadKey()` — перехватывает следующее нажатие клавиши на клавиатуре (возвращает структуру `ConsoleKeyInfo`).

### Считывание и конвертация данных

Метод `Console.ReadLine()` всегда возвращает тип `string`. Для математических вычислений строку необходимо преобразовать в целевой тип данных.

1. **Использование класса `Convert`:**

   ```csharp
   Console.Write("Введите возраст: ");
   int age = Convert.ToInt32(Console.ReadLine());

   Console.Write("Введите рост (м): ");
   double height = Convert.ToDouble(Console.ReadLine());
   ```

2. **Использование метода `Parse`:**
   ```csharp
   Console.Write("Введите баланс: ");
   decimal balance = decimal.Parse(Console.ReadLine());
   ```

## 2. Основные типы данных в C# и размер в памяти

Все базовые типы в C# являются псевдонимами (алиасами) соответствующих структур платформы .NET (Common Type System).

| Ключевое слово C# | Тип в среде .NET | Размер в байтах       | Диапазон значений / Описание                                                      |
| :---------------- | :--------------- | :-------------------- | :-------------------------------------------------------------------------------- |
| `byte`            | `System.Byte`    | 1 байт                | От 0 до 255 (целое без знака)                                                     |
| `sbyte`           | `System.SByte`   | 1 байт                | От -128 до 127 (целое со знаком)                                                  |
| `short`           | `System.Int16`   | 2 байта               | От -32 768 до 32 767                                                              |
| `ushort`          | `System.UInt16`  | 2 байта               | От 0 до 65 535                                                                    |
| `int`             | `System.Int32`   | 4 байта               | От -2 147 483 648 до 2 147 483 647                                                |
| `uint`            | `System.UInt32`  | 4 байта               | От 0 до 4 294 967 295                                                             |
| `long`            | `System.Int64`   | 8 байт                | От -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807                        |
| `ulong`           | `System.UInt64`  | 8 байт                | От 0 до 18 446 744 073 709 551 615                                                |
| `float`           | `System.Single`  | 4 байта               | ~1.5 × 10⁻⁴⁵ до ~3.4 × 10³⁸ (точность 6-9 цифр)                                   |
| `double`          | `System.Double`  | 8 байт                | ~5.0 × 10⁻³²⁴ до ~1.7 × 10³⁰⁸ (точность 15-17 цифр)                               |
| `decimal`         | `System.Decimal` | 16 байт               | ±1.0 × 10⁻²⁸ до ±7.9228 × 10²⁸ (высокая точность, 28-29 цифр, финансовые расчеты) |
| `bool`            | `System.Boolean` | 1 байт                | `true` или `false`                                                                |
| `char`            | `System.Char`    | 2 байта               | От `\u0000` до `\uffff` (одиночный символ Unicode UTF-16)                         |
| `string`          | `System.String`  | Переменный            | Ссылочный тип, последовательность символов UTF-16                                 |
| `object`          | `System.Object`  | 4 или 8 байт (ссылка) | Базовый ссылочный тип для всех типов в .NET                                       |

### Константы и приведение типов

- **Константы:** объявляются с помощью модификатора `const`. Значение задается при инициализации и не может быть изменено в процессе выполнения.
  ```csharp
  const double Pi = 3.1415926535;
  ```
- **Неявное приведение (widening):** выполняется автоматически, если целевой тип шире исходного и нет потери данных (например, `int` в `double` или `int` в `long`).
- **Явное приведение (narrowing):** требует оператора приведения `(тип)`, так как возможна потеря разрядов или переполнение (например, `(int)3.99` вернет `3`).

## 3. Примеры базовых программ

### Программа 1. Вывод приветствия и возраста

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите ваше имя: ");
        string name = Console.ReadLine();

        Console.Write("Введите ваш год рождения: ");
        int birthYear = Convert.ToInt32(Console.ReadLine());

        const int CurrentYear = 2026;
        int age = CurrentYear - birthYear;

        Console.WriteLine($"Здравствуйте, {name}! Ваш примерный возраст: {age} лет.");
    }
}
```

### Программа 2. Калькулятор площади и периметра прямоугольника

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите ширину прямоугольника: ");
        double width = double.Parse(Console.ReadLine());

        Console.Write("Введите высоту прямоугольника: ");
        double height = double.Parse(Console.ReadLine());

        double area = width * height;
        double perimeter = 2 * (width + height);

        Console.WriteLine($"Площадь: {area:F2}");
        Console.WriteLine($"Периметр: {perimeter:F2}");
    }
}
```

### Программа 3. Вычисление длины окружности с константой

```csharp
using System;

class Program
{
    static void Main()
    {
        const double Pi = 3.141592653589793;

        Console.Write("Введите радиус круга: ");
        double radius = Convert.ToDouble(Console.ReadLine());

        double circumference = 2 * Pi * radius;
        double area = Pi * radius * radius;

        Console.WriteLine($"Длина окружности: {circumference:F3}");
        Console.WriteLine($"Площадь круга: {area:F3}");
    }
}
```

### Программа 4. Демонстрация явного приведения и потери точности

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите число с плавающей точкой: ");
        double originalValue = Convert.ToDouble(Console.ReadLine());

        // Явное усечение дробной части
        int truncatedValue = (int)originalValue;

        // Явное сужение диапазона
        byte byteValue = (byte)truncatedValue;

        Console.WriteLine($"Исходное значение (double): {originalValue}");
        Console.WriteLine($"После приведения к int: {truncatedValue}");
        Console.WriteLine($"После приведения к byte (переполнение при > 255): {byteValue}");
    }
}
```

### Программа 5. Конвертер валют с фиксированным курсом

```csharp
using System;

class Program
{
    static void Main()
    {
        const decimal UsdToRubRate = 92.50m;

        Console.Write("Введите сумму в долларах США (USD): ");
        decimal dollars = decimal.Parse(Console.ReadLine());

        decimal rubles = dollars * UsdToRubRate;

        Console.WriteLine($"Сумма в рублях: {rubles:C2}");
    }
}
```
