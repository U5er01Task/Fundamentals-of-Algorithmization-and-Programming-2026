## 1. Краткая теоретическая шпаргалка

Массив — ссылочный тип данных (`reference type`), представляющий собой упорядоченный набор фиксированного числа однотипных элементов, расположенных в непрерывной области памяти.

### 1.1. Создание, индексация и обход

```csharp
// Объявление и создание массива на 5 ячеек (по умолчанию заполнен нулями)
int[] stats = new int;[1]

// Быстрая инициализация значениями
string[] items = { "Аптечка", "Фонарь", "Рация" };

// Индексация всегда начинается с нуля: от 0 до items.Length - 1
items = "Батарейка"; // замена элемента
int count = items.Length; // 3

// Цикл for: используется, когда нужен индекс или изменение элементов
for (int i = 0; i < items.Length; i++)
{
    Console.WriteLine($"Слот [{i}]: {items[i]}");
}

// Цикл foreach: используется для безопасного последовательного чтения
foreach (string item in items)
{
    Console.WriteLine($"- {item}");
}
```

### 1.2. Базовые алгоритмы обработки

```csharp
int[] points = { 45, 12, 89, 34, 67 };

// Поиск суммы и среднего арифметического
int sum = 0;
for (int i = 0; i < points.Length; i++)
{
    sum += points[i];
}
double average = (double)sum / points.Length;

// Поиск максимума и минимума вручную
int max = points;
int min = points;
for (int i = 1; i < points.Length; i++)
{
    if (points[i] > max) max = points[i];
    if (points[i] < min) min = points[i];
}
```

### 1.3. Методы статического класса System.Array

- `Array.IndexOf(array, value)` — возвращает индекс первого совпадения либо `-1`, если элемент не найден.
- `Array.Sort(array)` — сортирует массив по возрастанию на месте.
- `Array.Reverse(array)` — обращает порядок следования элементов на противоположный.
- `Array.Clear(array, index, length)` — обнуляет `length` элементов начиная с позиции `index` (числа заменяет нулями, строки — `null`).
- `Array.Resize(ref array, newSize)` — выделяет новый массив в памяти, копирует данные и меняет размер.

## 3. Разбор типовых примеров

### Пример 1. Инвентарь и поиск через Array.IndexOf

```csharp
using System;

class Program
{
    static void Main()
    {
        string[] inventory = { "Бинт", "Патроны", "Пусто", "Рация" };

        Console.Write("Введите предмет для поиска: ");
        string query = Console.ReadLine();

        int index = Array.IndexOf(inventory, query);
        if (index != -1)
        {
            Console.WriteLine($"Предмет '{query}' найден в слоте {index + 1} и готов к использованию.");
            inventory[index] = "Пусто";
        }
        else
        {
            Console.WriteLine("Предмет в инвентаре отсутствует.");
        }
    }
}
```

### Пример 2. Аналитика журнала действий через Array.Sort

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] hits = { 18, 45, 12, 60, 25 };

        Console.WriteLine("Исходный лог ударов: " + string.Join(", ", hits));

        Array.Sort(hits);
        Console.WriteLine($"Минимальный результат: {hits}");
        Console.WriteLine($"Максимальный результат: {hits[hits.Length - 1]}");

        Array.Reverse(hits);
        Console.WriteLine("Рейтинг эффективности (по убыванию): " + string.Join(", ", hits));
    }
}
```
